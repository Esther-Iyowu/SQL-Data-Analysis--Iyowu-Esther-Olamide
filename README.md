# SQL_Data_Analysis-Iyowu-Esther-Olamide

## Project Overview
This project focuses on Exploratory Data Analysis using MySQL. The objective was to extract meaningful business insights from a sales dataset by applying SQL queries for data retrieval, filtering, sorting, aggregation, and trend analysis.

The analysis was conducted using SQL fundamentals such as SELECT, WHERE, ORDER BY, GROUP BY, and aggregate functions including COUNT(), SUM(), and AVG().

---
## Tools Used
- MySQL
- MySQL Workbench
- SQL

---

## Project Objectives
The analysis aimed to answer key business questions such as:
- How many orders were processed?
- What is the total revenue generated?
- Which products generate the highest sales?
- Which payment methods are most commonly used?
- Which referral source drives the most orders?
- What are the monthly sales trends?
- Which month recorded the highest and lowest sales?

---
## Query Categories
The SQL queries in this project were organized into the following categories:

- Data Exploration (SELECT queries)
- Filtering & Sorting (WHERE, ORDER BY)
- Aggregation (COUNT, SUM, AVG)
- Grouping (GROUP BY analysis)
- Trend Analysis (monthly sales trends)
- Top Performers (best-selling products)
